# networking-labs

Labs, notes, and observations from learning networking from the packet level up.

## Contents
- `stp-lab/` — Spanning Tree Protocol: root election, failover, BPDU Guard
- `dhcp-lab/` — DHCP: baseline, rogue server attack, DHCP snooping
- `wireshark/` — Packet analysis notes and observations

## Why
Small experiments. Each one built to learn something, then archived.
